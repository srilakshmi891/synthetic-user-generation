# Synthetic User Generation Platform

An AI-powered application that generates realistic synthetic user personas for UX research and product design.

## Features

- AI-generated personas using Google Gemini/OpenAI
- FastAPI backend
- React + TypeScript frontend
- Interactive dashboard
- Persona gallery
- Detailed persona profiles
- Analytics and visualizations

## Tech Stack

- FastAPI
- Python
- React
- TypeScript
- Tailwind CSS
- Vite
- Google Gemini API
